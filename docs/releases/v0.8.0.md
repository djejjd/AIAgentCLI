# v0.8.0 热更新修复

## 界面变化

- 会话改为单行：厂商图标、厂商、自定义名称或固定短编号、Running / Ready 状态。
- 不再显示具体模型名称、上一轮输入或任务摘要。
- 状态标记缩至 5pt；选中行使用蓝灰底色，分支标签与项目名同行。
- 双击或右键 Rename 可改名，名称通过原生工作区标题保存，重载后保留。
- 项目加号提供空白终端和工具/模型预设；只有显式选择预设才启动 AI。
- 保留 Active 仅控制项目展开/收起、收藏入口默认隐藏和 Codex Interrupt 同步。

## 厂商识别修复

- 默认 GPT 会话没有显式 `-m` 时，从匹配会话的结构化模型元数据识别 OpenAI。
- 保留已有映射，支持带命名空间的模型 ID；未知值不会由工具名称猜测。
- 只提取厂商与显式名称，不把模型、输入正文、恢复命令或原始异常写入发布附件。
- 公开侧栏为空映射；安装端在本机生成，源码 worktree 不写入个人会话信息。

## 安装与发布

- 修正正式附件名称，使安装器下载的 `aia-projects.js` 与发布产物一致。
- 发布侧栏、安装器、厂商生成器、元数据读取器、安装事务模块及 SHA256SUMS。
- 下载后先验证全部执行附件的 SHA256；缺失或不匹配时不执行生成器、不修改旧版。
- 安装需要 Node.js 20+ 与可访问 cmux 的终端；更新前备份，校验失败恢复上一版。
- 开发安装也生成本机副本；正式热更新沿用同一个稳定源码 worktree 与侧栏入口。

## 验证与边界

- 发布分支完整本机回归 221/221 通过，含原生运行时、公开构建一致性、正式附件安装及回滚。
- CI 运行语法、公开构建和可移植回归；原生完整测试依赖本机 cmux Runtime。
- 厂商映射仍为显式快照刷新，不安装后台监听器；切换厂商后可重新生成并热加载。
- 六位身份短码不保证全局唯一；浅色、最窄侧栏及全键盘操作未完成全面验收。

## 安装事务与资源释放

| 当前阶段 | 事件 | 结果 | 资源与回滚 |
|---|---|---|---|
| 未开始 | 锁已占用 / 下载校验失败 | 失败 | 不覆盖安装、不释放他人锁 |
| 生成 | 元数据读取失败 / 安装文件变化 | 失败 | 释放本次锁与临时文件，保留原版或并发更新 |
| 校验 | 宿主拒绝 / 超时 | 失败 | 仍属本次事务才恢复；首次安装移除新入口 |
| 激活 | reload / select 失败 | 失败 | 同样按文件归属恢复，不覆盖并发更新 |
| 激活 | 全部通过且文件未变 | 完成 | 释放锁与临时文件，保留安装前备份 |

无后台任务或自动重试；锁在本机安装端覆盖生成、替换、校验和激活。
