# 上游来源与本地差异

## 代码谱系

1. cmux 官方示例 `Examples/CustomSidebars/workspaces.js` 提供基础侧栏运行时。
2. `s4ff0x/cmux-sidebar` 在其上增加嵌套分组、Agent 状态、拖拽和批量操作。
3. 本项目在该 fork 上增加按本机目录自动归组、项目式展示和当前交互调整。

## 本地新增

- 按本机工作目录规划项目分组，并使用 cmux 原生分组持久化。
- 单工作区也归组；同目录已有工作区自动归并。
- 归组请求一次只发送一条，等待宿主回显；超时后进入失败状态并要求显式重试。
- 项目模式隐藏与自动归组冲突的手动归组入口，并禁止跨项目拖动改变归属。
- `Active` 只控制项目展开和收起，不过滤项目内的终端或闲置对话。
- 左侧项目栏字号整体放大，原生侧栏最小宽度通过 `sidebarMinimumWidth` 单独设置。
- 收藏筛选和右键收藏入口默认隐藏，可通过 `SETTINGS` 恢复。

## 保留规则

- 不修改 cmux 本体，侧栏仍为单文件运行时。
- 不读取、记录或上传对话正文。
- 远程工作区、未知目录和非本机路径不进行自动归组。
- 保留 GPL-3.0-or-later 许可证及上游版权说明。

## v0.8.0 发布差异

新增厂商单行视图、原生名称持久化、显式启动预设和本机元数据生成。
`src/aia-projects.js` 为公开空映射构建；上游兼容视图 `src/cmux-sidebar.js` 保留。
本机映射、质量截图和开发目录不进入 Release；正式附件与安装器名称保持一致。
